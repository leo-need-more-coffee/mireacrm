# mireacrm-common

Общий обвяз Python-сервисов. Ставится из исходников, версия фиксируется
сервисом в `pyproject.toml`.

| Модуль | Что делает |
|---|---|
| `config` | базовые настройки: своя база, порты, брокер, адрес коллектора трасс |
| `db` | движок SQLAlchemy и фабрика сессий |
| `lifespan` | ресурсы процесса: движок, сессии, издатель событий, клиенты соседей |
| `deps` | зависимости FastAPI: контекст, сессия, издатель |
| `errors` | ошибки уровня приложения и их отображение в HTTP и gRPC |
| `identity` | разбор личности из заголовков шлюза и проброс её дальше |
| `events` | конверт доменного события и публикация в RabbitMQ |
| `consumer` | потребитель очереди: подтверждения, dead-letter, счётчики |
| `grpc_client` | канал к соседу: трасса, личность, отображение ошибок |
| `rpc` | сервер gRPC: рефлексия, перехватчики, отображение ошибок |
| `observability` | метрики HTTP и gRPC, `/metrics` |
| `tracing` | заголовок `traceparent` и его перенос через HTTP, gRPC и брокер |
| `health` | пробы живости и готовности |
| `pagination` | курсор постраничной выдачи |

Правил доступа здесь нет: принадлежность объекта проверяет сервис-владелец,
у каждого в `app/infra/access.py`.
